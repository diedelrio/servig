# 01 · Visión del MVP

Aplicación web para que un taller gestione reparaciones de herramientas (en y fuera de garantía) con trazabilidad completa:

Cliente → Herramienta → Recepción → Resguardo → Diagnóstico → Presupuesto → Aprobación/Rechazo → Repuestos → Reparación → Listo para retirar → Entrega.

## Principios
Simplicidad, seguridad, trazabilidad, bajo coste. Monolito modular, sin microservicios.

## Dentro del MVP (MUST)
Auth completa, roles, clientes, herramientas, recepción + resguardo imprimible, workflow con historial inmutable, diagnóstico, presupuestos versionados, aprobación digital, repuestos, portal cliente, emails con log, auditoría, dashboard.

## Fuera del MVP
Pagos/facturación, stock real, SMS/WhatsApp, multi-sucursal, firma manuscrita, 2FA, UI de edición de permisos.

## Localización
Español, EUR, IVA 21% configurable por línea.
